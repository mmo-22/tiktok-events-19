# 🎯 TikTok Live Reader — نسخة EulerStream

قارئ chat ومنصة فعاليات للبث المباشر على TikTok، يعتمد على سيرفر **[EulerStream](https://www.eulerstream.com/)**.

## المتطلبات
- Node.js 18+
- حساب ومفتاح API من [EulerStream Dashboard](https://www.eulerstream.com/dashboard)

## الإعداد

```bash
npm install
cp .env.example .env      # ثم ضع مفتاحك داخل الملف
npm start
```

ثم افتح: **http://localhost:3000**

### متغيرات البيئة

| المتغير | إلزامي | الوصف |
|---|---|---|
| `EULER_API_KEY` | ✅ | مفتاح EulerStream |
| `EULER_WS_URL` | ❌ | عنوان سيرفر الـ WS (افتراضي `wss://ws.eulerstream.com`) |
| `PORT` | ❌ | منفذ السيرفر (افتراضي 3000) |

> على Railway: أضف `EULER_API_KEY` في **Variables**.
> المتغير القديم `TIKTOOL_API_KEY` لا يزال مقروءاً كاحتياط، لكن يُفضّل التحويل للاسم الجديد.

## كيف يشتغل الاتصال

السيرفر يفتح WebSocket واحد لكل غرفة:

```
wss://ws.eulerstream.com?uniqueId=USERNAME&apiKey=KEY
  &features.bundleEvents=true
  &features.normalizeUniqueId=true
  &features.syntheticPresence=true
```

- المفتاح يبقى في السيرفر فقط ولا يصل للمتصفح.
- `bundleEvents` يجعل الأحداث تصل مجمّعة داخل `packet.messages` — نفس الصيغة المستخدمة في الكود.
- المتصفح يتواصل مع السيرفر عبر Socket.IO فقط.

### أكواد الإغلاق (EulerStream ClientCloseCode)

| الكود | المعنى | السلوك |
|---|---|---|
| 4400 / 4401 / 4403 | إعدادات أو مفتاح أو صلاحية خاطئة | إيقاف فوري، يحتاج تدخل يدوي |
| 4404 | البث غير مفتوح | إعادة محاولة منضبطة |
| 4005 | انتهى البث | إعادة محاولة منضبطة |
| 4429 | تجاوز عدد الاتصالات المسموح | محاولة واحدة بعد 10 دقائق ثم إيقاف |
| 4500 / 4556 / 4557 | خطأ من جهة TikTok | إعادة محاولة منضبطة |

# 🟢 دعم منصة Kick

المشروع صار يدعم منصتين. الألعاب والأوفرلايات ما تغيّر فيها ولا سطر — أحداث كيك تُترجم لنفس الصيغة الداخلية قبل ما توصلها.

## كيف تشغّل غرفة كيك

اكتب اليوزرنيم في لوحة الأدمن بهذي الصيغة:

```
kick:USERNAME      ← غرفة كيك
USERNAME           ← غرفة تيك توك (كما هي)
```

## الإعداد

1. أنشئ تطبيق من [kick.com/settings/developer](https://kick.com/settings/developer)
2. ضع `KICK_CLIENT_ID` و `KICK_CLIENT_SECRET` في البيئة
3. في إعدادات المطوّر بكيك، ضع رابط الـ webhook:
   ```
   https://YOUR-DOMAIN/webhooks/kick
   ```
4. فعّل الـ webhooks وتأكد إن صلاحية `events:subscribe` موجودة

> ⚠️ لو سيرفرك ما رد `200` على الـ webhook، كيك **يلغي الاشتراك تلقائياً** بعد 3 محاولات. الراوت عندنا يرد 200 فوراً قبل المعالجة تفادياً لهذا.

## جدول تحويل الأحداث

| حدث كيك | يصير داخلياً |
|---|---|
| `chat.message.sent` | `chat` |
| `channel.followed` | `follow` |
| `channel.subscription.new` / `renewal` | `gift` (وزن 100 لكل شهر) |
| `channel.subscription.gifts` | `gift` (وزن 100 لكل اشتراك مُهدى) |
| `kicks.gifted` | `gift` (`diamondCount` = قيمة الـ Kicks) |
| `livestream.status.updated` (غير مباشر) | `streamEnd` |
| استعلام دوري كل 30ث | `roomUserSeq` (عدد المشاهدين) |

أوزان الاشتراكات تقديرية — عدّلها في `src/providers/kick.js` داخل دالة `translate`.

## ما لا يوجد في كيك

كيك ما فيه **إعجابات** ولا **مشاركات** ولا حدث **دخول مشاهد**. الفعاليات اللي تعتمد عليها ما تشتغل على كيك:

| الفعالية | السبب | الحل |
|---|---|---|
| مزاد الكلمات | المزايدة بالإعجابات | بدّلها لمزايدة بالـ Kicks |
| أي أوفرلاي يعرض عدّاد الإعجابات | لا مصدر للبيانات | يبقى صفر |

باقي الفعاليات (حرب الكلمات، الكلمة السرية، التخمين، العجلة، السحب، الذاكرة، سباق الحروف…) تشتغل كلها لأنها على التعليقات.

## الفروق التشغيلية

| | تيك توك (EulerStream) | كيك (Public API) |
|---|---|---|
| نقل البيانات | WebSocket دائم | Webhooks (HTTP POST) |
| عدد المشاهدين | لحظي | استعلام كل 30ث |
| يحتاج رابط عام | ❌ | ✅ إلزامي |
| التحقق من المصدر | — | توقيع RSA |

## بنية الملفات الجديدة

```
src/providers/
  kick.js            ← ترجمة أحداث كيك + إدارة الاشتراكات
  kick-signature.js  ← التحقق من توقيع الـ webhook
```

> `kick-signature.js` يبني النص الموقَّع بصيغة `messageId.timestamp.body` ويجلب المفتاح العام من `/public-key`. راجع [توثيق كيك](https://docs.kick.com) لو تغيّرت الصيغة — التعديل في مكان واحد فقط.

## اختبار كيك بدون بث حقيقي

```bash
npm install
npm run test:kick
```

يشغّل سيرفر Kick وهمي + السيرفر الحقيقي، ويحاكي تعليقات وهدايا ومتابعات، ويتأكد إن حرب الكلمات وفعالية الخروج تحسب صح. ١٣ فحص.

> ملاحظة عامة (مو خاصة بكيك): أسئلة **الخروج** و**المليون** تقرأ الإجابة بـ `parseInt`، يعني تقبل `1 2 3 4` فقط. لو المشاهد كتب `٢` بالأرقام العربية ما تُحتسب.
